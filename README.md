# 地铁BAS系统 - PLC程序集合

## 📋 项目概述

这是一套完整的地铁楼宇自动化系统（Building Automation System, BAS）PLC程序，采用**IEC 61131-3结构化文本（ST）语言**编写。该系统包含1500+行代码，涵盖地铁运营的所有关键自动化功能。

## 🎯 系统模块

### 核心控制模块

#### 1. 照明控制系统 (LightingControl)
- ✅ 自动调光控制
- ✅ 日光感应补偿
- ✅ 占用传感器集成
- ✅ 亮度等级管理（0-1000）
- ✅ 能源节省模式

#### 2. HVAC空调通风系统 (HVACControl)
- ✅ 温度自动控制（PID调节）
- ✅ 湿度管理
- ✅ 供暖/制冷/除湿多模式
- ✅ 风扇变速控制（0-100%）
- ✅ 阀门精确控制（比例阀）

#### 3. 给排水系统 (WaterSystemControl)
- ✅ 液位实时监测
- ✅ 泵自动启停控制
- ✅ 进水/排水阀控制
- ✅ 液位高低报警
- ✅ 流量异常检测

#### 4. 电力监测系统 (PowerMonitoring)
- ✅ 三相电压/电流监测
- ✅ 总功率计算（kW）
- ✅ 功率因数分析
- ✅ 电压不平衡度检测
- ✅ 过压/欠压/过流报警

### 安全管理模块

#### 5. 门禁控制系统 (AccessControlSystem)
- ✅ 16路独立闸门控制
- ✅ 应急解锁功能
- ✅ 门体撬开报警
- ✅ 进出记录日志
- ✅ 定时自动上锁

#### 6. 人员流量管理 (PassengerFlowControl)
- ✅ IC卡验证识别
- ✅ 实时人数统计
- ✅ 拥挤度等级评估（0-3级）
- ✅ 超载限流控制
- ✅ 用户权限管理（普通/员工/管理）

#### 7. 消防报警系统 (FireAlarmSystem)
- ✅ 50个火灾探测器（烟感/温感/火焰）
- ✅ 三级报警逻辑（预警/确认/报警）
- ✅ 手动报警按钮
- ✅ 10秒确认延迟
- ✅ 自动联动反应

#### 8. 气体污染监测 (SmokeAndGasMonitoring)
- ✅ 烟雾浓度监测（0-100%）
- ✅ CO（一氧化碳）检测
- ✅ CO₂（二氧化碳）检测
- ✅ 符合WHO/GB标准
- ✅ 多参数告警阈值

#### 9. 应急疏散系统 (EmergencyEvacuation)
- ✅ 应急照明全自动启动
- ✅ 疏散路线指示灯（20路）
- ✅ 闪烁警示灯控制
- ✅ 语音播报系统
- ✅ 疏散时间自动计时

#### 10. 安全监测统计 (SecurityMonitoring)
- ✅ 报警历史记录（500条容量）
- ✅ 误报统计分析
- ✅ 系统可靠性评估
- ✅ 平均响应时间计算

### 集成控制模块

#### 火灾自动联动
```
火灾报警触发 → 
  ├─ 强制打开所有防火门
  ├─ 电梯强制返回一楼
  ├─ 停止送风系统
  ├─ 启动喷水灭火
  ├─ 全部应急照明开启
  └─ 启动紧急疏散程序
```

#### 拥挤限流联动
```
人员超容量 → 
  ├─ 关闭部分进口闸门
  ├─ 发送拥挤警告
  └─ 限制新进人员
```

#### 气体污染联动
```
污染浓度超标 → 
  ├─ 启动紧急通风
  ├─ 触发疏散程序
  └─ 上报监测中心
```

## 💡 使用示例

### 初始化系统
```st
PROGRAM Main
VAR
    lighting : LightingControl;
    hvac : HVACControl;
    fire_alarm : FireAlarmSystem;
END_VAR
BEGIN
    lighting.enable := TRUE;
    hvac.enable := TRUE;
    fire_alarm.enable := TRUE;
END_PROGRAM
```

### 启动应急疏散
```st
IF fire_alarm.evacuation_mode THEN
    emergency_evacuation.evacuation_trigger := TRUE;
    emergency_evacuation.audio_announcement := '紧急疏散，请立即离开！';
END_IF;
```

## 🔧 集成指南

### 所需硬件接口
- 模拟输入：温度、湿度、亮度、压力传感器
- 数字输入：门磁、烟感、温感、按钮、探头
- 数字输出：继电器控制照明、风扇、泵、阀门
- 通讯接口：Modbus/Profibus与上位机通讯

### PLC要求
- 支持IEC 61131-3 ST语言
- 最少10个以上模拟输入输出通道
- 至少30个数字I/O
- 实时时钟支持
- 最小10MB内存
